# 本地验收摘要与适用边界

## 结论的含义

- 验收日期：2026-11-10。
- MCP 适配修订：v12；软件：Siemens NX12.0.2.9；宿主 Python3.12.14 x64。
- 严格按该修订实际证据选择：77 PASS / 0 FAIL / 0 SKIP / 0 UNSUPPORTED。每个 PASS 代表记录的样例，不是全部参数组合。
- v12 记录中有 987 次标准 MCP 调用；先前版本的调用不被当成本修订 PASS。错误调用中包含预期负向输入拒绝、已修复缺陷及测试前提错误，最终通过不抹除这些历史事实。
- 编译、工具注册、RPC success、文件存在均不是独立通过依据；几何、状态、保存重开和需要时的 PDF/三维观察共同构成判据。

逐项工具状态见 [tool-validation.json](tool-validation.json)。该文件从实际内部矩阵提取工具名、同修订状态和成功调用计数，不公开个人路径、用户配置、原始日志或课程文件。它是维护者的脱敏实测摘要，不是下游机器的自动合格证书。

## 未作出的保证

1. 这些样例不覆盖任意自交草图、病态薄壁、所有边组合、全部单位混合、曲面或全部约束参数。英制部件混入mm装配、英制工程图及英制STEP组合未完成穷举。
2. 面法线仅平面提供单一向量；重心是均匀体积重心。材料标题字段是字符串，不等于赋物理密度。包围盒是ABS轴对齐包围范围。
3. 镜像/阵列验收为复制体数量、位置及几何；不宣称都产生可编辑的原生参数化阵列特征。未公开完整NX特征依赖图或任意跨重开草图编辑。
4. BOM是可编辑快照、balloon是静态图纸点引线。替换只在未约束组件实测，不证明任意受约束组件的拓扑自动重映射；子装配是共享prototype，不是flexible实例覆盖。
5. 粗糙度及GDT未证明关联指定面；GB/T样式布局未做完整国标认证。主图R4是Ø8孔边的工具测试，不是把实际R2外圆角标成R4，也不是生产图纸的最优完整尺寸方案。
6. DXF结构解析不等于外部CAD显示/往返；DWG仅验证真实导出、非空和签名。STEP不保证保留特征历史、装配约束/树、颜色或全部metadata；本次往返是AP214单实体。
7. 图片相关工具的本轮样例是明确尺寸阶梯轴及缺尺寸拒绝；不执行OCR，不推广到任意图纸、齿轮或箱体的全自动识图成功。
8. 未执行长期soak、并发客户端竞争、断管/断电故障注入或内存泄漏证明；备份CRC和SHA核查不是实际恢复演练。
9. 扫掠未注册为工具，但本机NX12 SDK存在相关builder，不能标为NX12 UNSUPPORTED。未注册能力不混入77项统计。
10. Journal Skill 1.5.0只完成仓库静态检查和示例journal静态检查；没有运行其53个NX用例。上游版本、求解器授权及已知崩溃探针边界必须另行核对。

实际安装和启动脚本测试使用已有 PowerShell 7。本次环境的 Windows PowerShell 5 执行策略禁止 `.ps1`，没有改策略或使用 Bypass；因此宿主 stdio 配置已改为直接使用 Python 入口，PowerShell 包装器仅保留为可选方式。

公开副本移除了 STEP 安装目录解析中的维护者固定路径回退，改由 `NX_HOME` / `UGII_BASE_DIR` 指定，缺失或不匹配时显式失败；新增直接 Python stdio 启动入口及署名、许可证元数据等整理，没有改变几何算法。

这组结果只证明一个 Windows 环境中的安装、编译、stdio发现、新NX会话及一个最小几何用例；**不是公开副本重新执行全部77项几何回归**，也不是所有机器、包源或许可证配置的部署保证。下载者应先执行INSTALL中的独立方块测试，再逐个验证所需功能。公开包不含SDK或许可证，构建后DLL哈希也可能受编译环境影响；以源码版本、构建日志和实际运行校验共同确定安装。
